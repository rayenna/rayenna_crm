# Legacy help drafts (not loaded in the app)

Markdown under `content/docs/` is **not** bundled into Help. The live help system loads from:

- `content/getting-started/`, `roles/`, `modules/`, `dashboard/`, `zenith/`, `security/`, `faq/`, `training/`

Use **Help** in the CRM (`/help/...`) or edit the section folders above. Do not link to files in this `docs/` tree from production help content.
