# Dashboard

The **classic Dashboard** is your in-menu analytics home: filters at the top, role-specific KPIs, **Quick Access** tiles that open **Projects**, and charts you can **click through** to filtered lists.

For the full-screen experience, use **[Zenith ✦](/help/zenith#zenith-command-center)** (same FY / Quarter / Month rules, drawer-first drill-downs).

> **Tip:** Press **?** on the Dashboard page to open this help. Shortcuts: [Getting Started → Keyboard shortcuts](/help/getting-started#keyboard-shortcuts) (**Ctrl+Shift+D** / **⌘⇧D** for Dashboard).

## Classic Dashboard vs Zenith

| | **Classic Dashboard** | **Zenith ✦** |
| :-- | :-- | :-- |
| **Open from** | Top menu → **Dashboard** | Dashboard menu → **Zenith ✦** |
| **Best for** | Familiar layout, chart → **Projects** in one click | Command center, Hit List, Solar News, AI Insights, offline PWA |
| **Drill-down** | Usually **straight to Projects** | **Quick Actions** drawer → **Open in Projects →** |
| **Filters** | FY, Quarter, Month | Same rules — [Filters & dates](#dashboard-filters) |

Deep dive: [Zenith command center](/help/zenith#zenith-command-center)

## Scrolling announcements (Dashboard)

Below the **Dashboard** title, a **marquee** scrolls product updates. It currently alternates:

1. **My Day** — CRM-linked **Tasks**, **Journal**, and **Reminders**. Open with **Ctrl+Shift+M** (**⌘⇧M**) or the **☀** icon (badge = incomplete tasks). Pin from **Today's plan**, **Things needing attention**, or Zenith **Hit List** with **+ My Day**.
2. **Zenith** — Full-screen command center under **Dashboard** menu → **Zenith ✦**.

Full **My Day** behaviour: [Zenith → My Day](/help/zenith#my-day-personal-productivity-drawer).

## By role — start here

| Role | Your dashboard highlights |
| :-- | :-- |
| **Sales** | YoY band, Quick Access (own pipeline), lead-source charts, PE card — data **scoped to you** |
| **Operations** | Quick Access band, optional **Pending Subsidy** list, execution charts, panel/inverter bars |
| **Finance** | Top revenue / received / outstanding KPIs, Quick Access, loan-by-bank chart |
| **Management** | YoY band, executive Quick Access, treemap, PE card — **no** Things needing attention card |
| **Admin** | Management-style layout **plus** Things needing attention (like Sales/Ops) |

Permissions: [Roles → Permission matrix](/help/roles#permission-matrix). Data modules: [Modules](/help/modules).

## If the dashboard fails to load

When the API is unreachable, you see **Unable to load dashboard** with **Try again**. Check network/VPN, then retry. Numbers refresh when you change filters or reload the page.
