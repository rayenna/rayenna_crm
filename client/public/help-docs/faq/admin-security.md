# Admin and security

**Administrators only** unless noted.

### Where do I manage users?
Top menu → **Users**. Create accounts (email, name, password, role), **Reset password** (24-hour link), or **Delete** users. Full guide: [Security → Users](/help/security#users).

### What is the Audit & Security page?
**Audit & Security** shows login summary tiles, **Security insights** charts, **Recent failed logins**, and an **Activity timeline** (user/project/ticket/proposal actions). Export CSV, PDF, or **signed PDF**. Guide: [Security → Audit and Security](/help/security#audit-and-security).

### How do I export audit logs?
Set **Action type**, **Entity type**, and dates on the **Activity timeline**, then use **Export CSV**, **Export PDF**, or **Signed audit export** in the export card above the timeline. Signed PDF includes generation date and exporter email. [Security → Audit and Security](/help/security#audit-and-security).
