# Roles and access

### What user roles exist?
**Administrator (Admin)**, **Sales**, **Operations**, **Finance**, and **Management**. Your role controls menus, visibility, and what you can edit. Full tables: [Roles → Permission matrix](/help/roles#permission-matrix).

### Why can't I see a menu item or feature?
Menus are **role-based**. Examples:

| Feature | Who sees it |
| :-- | :-- |
| **Users**, **Audit & Security** | Admin only |
| **Tally Export** | Finance and Admin |
| **Reports** | Admin, Management, Operations, Finance, Sales — **which pack** depends on role (Sales = own book; **Margin & Mix** is Admin / Management / Finance; **Lost Deals** is Admin / Management) |
| **Solar Hub** | Operations and Admin |
| **Support Tickets** | Not Finance |
| **More → Proposal Engine** | Sales, Operations, Finance, Management, Admin (same as Dashboard / Zenith menu roles) |

If you need access, contact your administrator. Per-role guides: [Roles](/help/roles).

### Why can't I edit or delete something?
Permissions vary by role and record:

- **Admin** — broad edit/delete (users, projects, customers when rules allow).
- **Sales** — own assigned customers and projects.
- **Finance** — payment fields on projects; no project creation.
- **Management** — customer create/edit and reassignment; mostly **view** on projects.

Examples: only **Admin** deletes users; **Admin** deletes customers **with no projects**; **Finance** edits payments. See [Permission matrix](/help/roles#permission-matrix) and the relevant [Modules](/help/modules) guide.
