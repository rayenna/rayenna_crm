# Troubleshooting

### The page is not loading
- Check your internet connection
- Refresh the page (**F5** or **Ctrl+R** / **⌘R**)
- Clear browser cache or try another browser
- Contact your administrator if it persists

### I can't log in
- Verify email and password; check **Caps Lock**
- Rayenna shows plain-language errors (not raw server messages)
- Ask an Administrator for a **Reset password** link — [Security → Users](/help/security#users)

### I can't see certain features
- Check your **role** — [Permission matrix](/help/roles#permission-matrix)
- Some menus are hidden by design (e.g. Finance has no Support Tickets)
- Contact your administrator if you need access

### Data is not updating
- Refresh the page
- On Dashboard, change or **Reset** FY / Quarter / Month filters
- Confirm you have **edit** permission for that record
- Contact support if numbers still look wrong after refresh

### Dashboard numbers don't match what I expect
- Check **FY / Quarter / Month** on Dashboard (and Zenith — same rules)
- Clear filters to see unfiltered totals, or select the intended period
- Refresh to load the latest server data

### Zenith shows Offline or stale numbers
- Wait until the command bar shows **Live** (needs connectivity)
- If using the CRM as an **installed app (PWA)**, open Zenith **online** with your usual filters before going offline
- Offline mode may show the **last successful load**; some drawer edits **queue** until **Sync**
- **My Day**, **Solar News**, and **Open in Projects →** need a live connection
- Full detail: [Zenith → Mobile, offline, and limits](/help/zenith#mobile-pwa-and-limits)

### Help content looks wrong or won't load
- Refresh and open Help again
- Switch sections in the sidebar (e.g. Getting Started) then back to FAQ
- Try another browser or clear cache

### Export not working
- Confirm your **role** allows that export (Tally, audit, Admin list exports)
- For **Audit & Security**, set timeline filters before export
- Check for error toasts; retry on a stable connection
