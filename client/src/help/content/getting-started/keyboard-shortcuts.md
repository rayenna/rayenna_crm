# Keyboard Shortcuts

## Command palette (anywhere)

| Shortcut (Win/Linux) | Mac | Action |
| :-- | :-- | :-- |
| **Ctrl+K** | **⌘K** | **Command palette** — search and jump to create, lists, and common screens. Works even while typing in a field. (**Ctrl+Shift+K** / **⌘⇧K** still opens Support Tickets.) |

Press **Ctrl+K** (Windows/Linux) or **⌘K** (Mac) from **any** CRM page. Type to filter; **Enter** runs the highlighted row; **Esc** closes. Items are **filtered by your role** — you only see actions you are allowed to use. **Go to Proposal Engine** opens PE **Customers / Projects** with your CRM login and no project pre-selected (same as **More → Proposal Engine**).

The same task set also works from **Ask Zenith** (type the phrase and press Ask). Analytics questions (charts/tables) are Ask-only — see [Ask Zenith](/help/zenith#ask-zenith-natural-language).

From the palette you can also choose **Ask Zenith…** (opens the floating Ask window on laptop) or type a question and pick **Ask Zenith: “…”** to run it. On a phone on Zenith, those still open the **Ask** tab. The header **Ask Zenith** button opens the same window from **any** CRM page.

### What you can run from the palette

| Group | Actions (when your role allows) |
| :-- | :-- |
| **Create** | New Customer · New Project · Create Support Ticket · New User |
| **Lists** | Overdue Support Tickets · Open Support Tickets (queue) · Solar Hub Support Tickets · Proposal-stage / Confirmed / Under Installation projects · Pending Subsidy · Availing Loan · Projects Needing Review · Proposal Engine — Not Started / Drafts / Proposal Ready |
| **Go to** | Zenith · Customers · Projects · **Reports** · **Sales Review** · **Funnel Velocity** · **Delivery Control** · **Collections & Cash** · **Margin & Mix** · **Lost Deals** · Support Tickets · Proposal Engine · Dashboard (classic) · Solar Hub · Solar Hub Provisioning · Solar Hub — Unlinked Plants · Solar Hub Maintenance · Tally Export · Users · Audit & Security · Change Password · Open Help · Open My Day · Open My Day Journal · Show Tip of the Day |
| **Search** | Type a name or keyword to also get **Search customers for…** / **Search projects for…** |

**Tip:** Palette is fastest for navigation and creates. Use **Ask Zenith** when you want an insight, chart, or table from CRM data.

## Letter shortcuts

When focus is **not** in a text field, **textarea**, **select**, or **contenteditable** area:

- **?** — Open **Help** for the current area (from **Dashboard** → Dashboard help; from **Zenith** → Zenith help at **Command Center**).

| Shortcut (Win/Linux) | Mac | Action |
| :-- | :-- | :-- |
| Ctrl+Shift+D | ⌘⇧D | **Dashboard** |
| Ctrl+Shift+C | ⌘⇧C | **Customers** (Admin, Sales, Operations, Finance, Management) |
| Ctrl+Shift+P | ⌘⇧P | **Projects** (same roles as Customers) |
| Ctrl+Shift+K | ⌘⇧K | **Support Tickets** (Admin, Sales, Operations, Management — not Finance) |
| Ctrl+Shift+Z | ⌘⇧Z | **Zenith** (roles that see Zenith under the Dashboard menu) |
| **/** or **A** | **/** or **A** | **Open Ask Zenith** — on the **Zenith** page, when focus is not already in a field (laptop: floating window; phone: Ask tab). From other pages, use the header **Ask Zenith** button. |
| **Esc** | **Esc** | **Close Ask Zenith** when the floating window is open (same as title-bar **×**). On a **Help** page, **Esc** returns to the Dashboard. |
| Ctrl+Shift+M | ⌘⇧M | **My Day** — personal Tasks, Journal & Reminders ([details](/help/zenith#my-day-personal-productivity-drawer)) |
| Ctrl+Shift+N | ⌘⇧N | **New customer** — opens the create form (Sales, Management, Admin) |
| Ctrl+Shift+E | ⌘⇧E | **New project** — opens the new-project screen (Admin, Sales) |

On a **Help** page, **Esc** returns you to the **Dashboard**. When the **Ask Zenith** floating window is open, **Esc** closes that window first.

## My Day shortcut

**Ctrl+Shift+M** (⌘⇧M) or the **☀** icon in the top nav opens **My Day** — your private tasks, journal, and reminders. You can also open it from the **command palette** (**Open My Day**). Pin follow-ups from **Today's plan**, **Things needing attention**, or Zenith **Hit List** with **+ My Day**. Full behaviour: [Zenith → My Day](/help/zenith#my-day-personal-productivity-drawer).
