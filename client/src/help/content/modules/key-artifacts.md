# Key Artifacts Module

**Key Artifacts** stores project files in the cloud (photos, PDFs, Office documents) on each project’s **detail** and **edit** screens. Files are organized by **category** with optional descriptions.

## At a glance

| Role | Upload | View / download |
| :-- | :-- | :-- |
| **Sales** | Own projects only | Projects you can open |
| **Operations** | Projects in Confirmed → Subsidy Credited | Same gated list |
| **Admin** | Any project | Any project |
| **Finance / Management** | — | View on projects you can open |

→ [Roles → Permission matrix](/help/roles#permission-matrix) · [Projects](#projects-module)

## Where to find artifacts

1. Open a **project** (list row or project number).  
2. **Project detail** — **Key Artifacts** section lists uploaded files (view / download).  
3. **Edit project** — scroll to **File Uploads** / Key Artifacts to add files.

Use the **Has Artifacts** filter on the **Projects** list to find projects with uploads.

## Upload a file

1. **Projects** → open project → **Edit**.  
2. In **File Uploads**, choose a **file**, **category** (required), and optional **description**.  
3. Click **Upload File**.

**Categories:**

- **Photos / Videos**  
- **Documents** (PDF, Word, etc.)  
- **Sheets** (Excel, CSV)

**Limits (live app):**

- Up to **10 files per project**  
- Max **10 MB** per file  
- Allowed types: common **images**, **PDF**, **Excel**, **Word** (invalid types are rejected with a message)

## View and download

On **project detail**, each artifact shows category, description, and download. Anyone who can open the project can view artifacts; only permitted roles can upload (see table above).

## Best practices

1. Upload site photos and signed documents **as soon as** they are available.  
2. Pick the **right category** so filters and audits stay meaningful.  
3. Add a short **description** (e.g. “DISCOM feasibility letter — Jan 2026”).  
4. Do not upload unrelated or personal files — storage is for **project evidence**.  
5. If upload fails, check file **size** and **type**, then retry; contact **Admin** if the limit blocks a legitimate bundle.
