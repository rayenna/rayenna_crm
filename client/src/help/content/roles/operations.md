# Operations Role Guide

You drive **execution** after the sale is confirmed: installations, compliance dates, subsidies, and field issues. You see a subset of projects by **status**, but can edit both **lifecycle** and **Sales & Commercial** fields on those projects.

## At a glance

| You can | You cannot |
| :-- | :-- |
| View/edit projects in **Confirmed → Subsidy Credited** | See **Lead**, **Site survey**, **Proposal**, or **Lost** in your default project list |
| Update **installation**, **DISCOM**, **subsidy**, and related dates | Create new projects |
| Edit **Sales & Commercial** and **financing** on allowed projects | Record **payments** (Finance / Admin) |
| **Support tickets** on any project you can open | **Tally export**, **Users**, or **Audit & Security** |
| **Operations** dashboard and **Zenith** (operations layout) | Delete projects or bulk-export lists |

→ [Permission matrix](#permission-matrix) · [Modules → Projects](/help/modules#projects-module)

## Your dashboard

**Typical metrics:** pending installation, subsidy submitted / credited, installation pulse, funnel views.

**Pending subsidy** lists help you chase delayed credits — open a row to jump to the project.

**Filters:** financial year and month apply across cards and charts.

Use **Zenith ✦** for installation-focused panels and chart drill-downs. [Zenith help](/help/zenith#zenith-command-center)

## Which projects you see

**Included statuses:**

- Confirmed  
- Installation  
- Completed  
- Completed — subsidy credited  

**Excluded:** Lead, Site survey, Proposal, Lost (Sales and Management handle early pipeline).

If you need an early-stage project, ask the assigned **Sales** user or **Management** — do not expect it in your Projects list.

## Day-to-day project work

### Find work

1. **Projects** → filter by status (Confirmed, Installation, etc.).
2. Or start from dashboard **Pending installation** / subsidy widgets.
3. Search by customer name or project number.

### Update lifecycle

Open project → **Edit** → **Project lifecycle / execution**:

- MNRE / DISCOM registration and feasibility dates  
- Installation completion and completion report dates  
- Subsidy submission and credit dates  
- Panel / inverter brands where your process requires them  

Save after each batch of updates so audit history stays clear.

### Sales & commercial (on your projects)

On the same edit form you may update **lead source** (and required detail fields), **financing / loan** fields, and related commercial data when Operations needs to correct handoff information. Sales still owns early pipeline; you own delivery.

### Lost projects

You generally **do not** see Lost projects. If a confirmed project is marked Lost, Sales/Admin workflows apply.

## Support tickets

Operations often owns site and service issues:

1. Open the project → create or update a **support ticket**.  
2. Add follow-ups with notes and optional follow-up dates.  
3. **Close** when resolved.

**Management** and **Sales** can also manage tickets; **Finance** cannot.

## Customers module

**View only** — you can open customers linked to your projects but cannot create or edit customer master records (except indirectly via project links). Escalate customer detail changes to **Sales** or **Management**.

## Payments

View **payment status** on projects. **Finance** enters amounts and dates in **Payment tracking**.

## Exports and admin tools

No **Tally export** or **Projects Excel/CSV** — request from **Finance** or **Admin** if needed.

## Daily rhythm

1. Review **dashboard** / **Zenith** for pending installs and subsidy backlog.  
2. Update **lifecycle dates** as milestones complete.  
3. Raise **support tickets** for blockers on site.  
4. Coordinate with **Sales** when commercial fields on confirmed jobs need correction.  
5. Pin follow-ups in **My Day** (**Ctrl+Shift+M** / **⌘⇧M**).
