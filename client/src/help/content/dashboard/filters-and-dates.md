# Dashboard filters

Use the filter bar at the top of the Dashboard to focus on a period. **Quick Access** tiles, **Year-on-Year** KPIs, **Payment Status**, **Proposal Engine**, and most charts respect these filters.

## Financial Year (FY)

- One or more years in **April–March** format (e.g. **2024-25**).
- Options come from project data in the CRM (same source as Zenith).

## Quarter

- Available only when **exactly one** FY is selected.
- **Q1** Apr–Jun · **Q2** Jul–Sep · **Q3** Oct–Dec · **Q4** Jan–Mar.

## Month

- Available only when **exactly one** FY is selected.
- Months follow FY order (April through March).
- If you select quarters first, only months inside those quarters appear.

## Multiple FYs

If you select **more than one** FY, **Quarter** and **Month** are disabled. Use **Clear Filter** (or clear FY) to reset and see all periods.

## Projects list parity

Open **Projects** from a Quick Access tile or chart drill-down — the URL keeps the same **FY / quarter / month** query parameters so the grid matches what you saw on the Dashboard.

> **Tip:** Filter rules match [Zenith → Filters](/help/zenith#filters-and-reset) so numbers stay comparable between classic Dashboard and Zenith.

## What filters affect

| Area | Follows FY / Q / M |
| :-- | :-- |
| Quick Access metric tiles | ✓ |
| Payment Status & Proposal Engine cards | ✓ |
| Year-on-Year KPI band | ✓ |
| Most charts | ✓ |
| Today's plan CRM suggestions | ✓ (within explorer slice) |
| Things needing attention rows | ✓ |

See [Year-on-Year KPIs](#year-on-year-kpis) for when comparison badges show **N/A**.
