Most issues show as a **warning light**, **error code**, or **sudden drop to zero generation** on the inverter display or monitoring app. Follow these steps before requesting a service visit.

## Step 1 — Note the error code

Write down the code exactly as shown (e.g. `F35`, `Grid lost`). Check the inverter manual or sticker inside the cover for code meanings.

## Step 2 — Quick checks (safe only)

- **AC breaker / isolator** — Confirm inverter supply breaker is ON
- **Grid present** — Neighbours have power; not a prolonged KSEB outage
- **DC isolator** — Should be ON during normal operation (do not open DC side unless trained)
- **Display** — Screen lit and responsive
- **Wi-Fi / dongle** — If monitoring uses Wi-Fi, router is online (affects Track, not always generation)

**Never** open live electrical panels if you are unsure. Stop if you see burning smell, smoke, or water inside the inverter box.

## Step 3 — Safe reset (if manual allows)

Some brands allow a single reset after grid returns from outage. Follow **only** the manufacturer procedure. If the fault returns within minutes, do not keep resetting.

## Step 4 — Report in Solar Hub

1. **Maintain → Report an issue**
2. Subject: include error code if known
3. Describe when it started and weather conditions
4. Attach a photo of the display if safe

For **zero generation on clear days for 48+ hours**, call **Support → Emergency** if you suspect a safety fault; otherwise submit a report and we will prioritize.

## Common situations

| Symptom | Likely cause | Action |
|---------|--------------|--------|
| Zero at night | Normal | None |
| Zero all day, sunny | Grid fault, breaker, or inverter fault | Check breakers; report if persists |
| Low vs neighbours | Shading, soiling, or sizing | Check trees; see panel cleaning guide |
| App offline, inverter OK | Monitoring only | Wi-Fi / logger issue — still report if prolonged |

## Warranty

Manufacturer defects may be covered under **Maintain → Warranty**. Rayenna will confirm eligibility when you submit a report.
